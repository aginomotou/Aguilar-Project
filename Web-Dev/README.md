# Web-Dev Learning Material

A guided learning path for building a portfolio (frontend) and APIs (backend).

---

## Roles

| Role | Tracks |
|------|--------|
| **Frontend** | Track 1 — Frontend Portfolio Builder |
| **Backend** | Track 2 — Backend APIs & Supabase + Track 3 — API Testing |

---

## How to Get Started

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally.
3. **Follow the guide** for your role:
   - Frontend members: start with `01-Frontend-Portfolio/module-01-html/guide.md`
   - Backend members: start with `02-Backend-APIs/module-01-cors/guide.md`
4. Complete each module in order. Each module has a **task** with acceptance criteria.
5. Frontend members deploy their finished portfolio to **Vercel** (see `module-06-assembly/guide.md`).

## Rules

- Each member works in their **own fork** — no shared files.
- Frontend and backend track independently. No fullstack requirement.
- Each module has a clear **task** and **acceptance criteria**. Check them before moving on.
- Stretch goals are optional — tackle them if you finish early.
