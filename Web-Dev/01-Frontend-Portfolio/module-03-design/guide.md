# Module 03 — Design Principles

## Learning Objective
After this module, you should be able to apply core design principles (color, typography, spacing, layout) to create a visually polished portfolio layout.

## Concepts
- **Color Theory**: Use a primary, secondary, and accent color. Stick to 2–3 colors total. Tools like Coolors.co or Adobe Color help build palettes.
- **Typography**: Choose 1 heading font and 1 body font (or use a well-paired system font stack). Limit yourself to 2 font families. Set a comfortable line-height (1.5–1.7) and paragraph max-width (60–75 characters).
- **Spacing**: Use consistent spacing multiples (4px, 8px, 16px, 24px, 32px, etc.). This creates visual rhythm.
- **UI Patterns for Portfolios**: Hero section (large intro), Projects grid, About me, Contact form. Each section should have clear visual hierarchy.
- **Whitespace**: Let the design breathe. Generous padding and margins make content easier to scan.

## Task
Design and implement your portfolio's visual identity:
1. Pick a color palette (3–4 colors). Write the hex codes as CSS custom properties in `:root`.
2. Choose fonts — Google Fonts or system stack. Apply them consistently.
3. Apply the spacing system to all sections.
4. Design a hero section with your name, a short tagline, and a call-to-action button.
5. Style your project cards to be visually distinct and scannable.

> **Need design help?** Check `resources/resources.md` in this module for recommended tools and references.

### Acceptance Criteria
- Color palette has no more than 4 colors used consistently.
- Typography uses at most 2 font families.
- Spacing is consistent across sections (no arbitrary pixel values).
- Hero section is visually distinct and draws the eye.
- The portfolio looks polished at a glance (show it to someone — does it look intentional?).

## Stretch Goal
- Create a style guide page that documents your colors, fonts, spacing tokens, and component colors
