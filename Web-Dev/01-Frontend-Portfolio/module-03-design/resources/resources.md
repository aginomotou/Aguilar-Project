# Design Resources

## Color Palette Tools
- [Coolors](https://coolors.co/) — generate and export color palettes
- [Adobe Color](https://color.adobe.com/) — create palettes using color theory rules
- [Contrast Checker](https://webaim.org/resources/contrastchecker/) — verify WCAG color contrast ratios

## Typography
- [Google Fonts](https://fonts.google.com/) — free, open-source font library
- [Type Scale](https://typescale.com/) — generate a modular type scale
- [System Font Stack](https://system-fonts.net/) — fast, native font reference

## Spacing & Layout
- **8pt Grid System**: Use multiples of 8 for spacing (8px, 16px, 24px, 32px, 48px, 64px)
- [8pt Grid](https://8pt.grid.layout/) — interactive spacing tool
- [MD Layout Visualizer](https://layout.visualizer.app/) — visual reference for padding and margin

## UI Pattern References
- [Landing Page Design](https://landingpagelove.com/) — curated landing page examples
- [UI Gradients](https://uigradients.com/) — color gradient inspiration
- [Real World CSS Examples](https://realworldcss.com/) — practical CSS patterns
