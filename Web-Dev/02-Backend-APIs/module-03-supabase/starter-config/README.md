# Supabase Starter Config

Create your own Supabase project at https://supabase.com.

## Steps
1. Sign up for a free Supabase account
2. Create a new project
3. Go to Settings → API to get your URL and keys
4. Use the Table Editor to design your tables
5. Enable Row Level Security (RLS) for security
