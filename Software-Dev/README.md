# Software-Dev Learning Material

A guided learning path for building a Quiz app using Flutter (frontend) and Python FastAPI (backend).

---

## Tracks

| Track | Modules | Who |
|-------|---------|-----|
| **01-Flutter** | Calculator (Module 1), To-Do List (Module 2) | Frontend team |
| **02-Backend** | API Architecture, CORS, Database, Auth, Testing | Backend team |

---

## How to Get Started

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally.
3. **Follow the guide** for your track:
   - Frontend members: start with `01-Flutter/module-01-calculator/guide.md`
   - Backend members: start with `02-Backend/module-01-api-architecture/guide.md`
4. Complete each module in order. Each module has a **task** with acceptance criteria.

---

## Rules

- Each member works in their **own fork** — no shared files.
- Frontend and backend tracks are separate — no cross-pollination.
- Each module has clear **task** and **acceptance criteria**. Check them before moving on.
- Stretch goals are optional — tackle them if you finish early.
