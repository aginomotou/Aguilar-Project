# Quiz Template Project

This is where you should place your final quiz app project (the real project).

## How It Works
- Build your full quiz app combining Flutter frontend (from the Frontend track) and FastAPI/Python backend (from the Backend track)
- Frontend: Flutter app with quiz UI, scoring, timer, and categories
- Backend: FastAPI endpoints for fetching questions, submitting answers, storing scores
- Database: Supabase or SQLite for persisting questions and results

## File Structure
```
quiz-template/
├── frontend/           ← Flutter app code
│   └── lib/
│       └── main.dart
│   └── pubspec.yaml
├── backend/            ← FastAPI/Python API code
│   └── main.py
├── database/           ← Models, migrations, seed data
└── README.md           ← This file
```

## Submission
- All final quiz project code goes in this folder
- Make sure both frontend and backend work together before submitting
