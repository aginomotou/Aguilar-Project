# Calculator Template Project

This is where you should place your final calculator app project.

## How It Works
- Start with the calculator starter files from `01-Flutter/module-01-calculator/starter-files/`
- Customize the UI (colors, layout, button styles, fonts) to make it your own
- Keep all the Dart logic intact — just modify the visual design
- When complete, move your project folder here so it's organized and easy to find

## File Structure
```
calculator-template/
├── lib/
│   └── main.dart        ← Your modified calculator code
├── pubspec.yaml         ← Dart/Flutter dependencies
└── README.md            ← This file
```

## Submission
- All final calculator code goes in this folder
- Make sure the app runs without errors before submitting
