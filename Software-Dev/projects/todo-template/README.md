# To-Do List Template Project

This is where you should place your final to-do list app project.

## How It Works
- Start with the to-do list starter files from `01-Flutter/module-02-to-do-list/starter-files/`
- Customize the UI (colors, layout, card styles, input design) to make it your own
- Keep all the Dart logic intact — just modify the visual design
- When complete, move your project folder here so it's organized and easy to find

## File Structure
```
todo-template/
├── lib/
│   └── main.dart        ← Your modified to-do list code
├── pubspec.yaml         ← Dart/Flutter dependencies
└── README.md            ← This file
```

## Submission
- All final to-do list code goes in this folder
- Make sure the app runs without errors before submitting
